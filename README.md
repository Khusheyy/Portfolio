# Portfolio

Minimal dark-themed personal portfolio inspired by a terminal-style about page.

## Running locally

- **Open directly**: Double-click `index.html` to open it in your browser.
- **Or with a simple server** (recommended for future expansion):

  ```bash
  cd Documents/portfolio
  npm install serve -g
  serve .
  ```

Then visit `http://localhost:3000` (or the URL `serve` prints).

## Customization

- **Name / intro text**: Edit the copy inside `index.html` in the `about me` section.
- **Social links**: Replace `href="#"` and `you@example.com` in the social icons with your real profiles.
- **Avatar**: Replace the initials inside the `.avatar` element with an image or your preferred initials.
